# HGhub

**基于 Rust、Tauri 2 与 JavaScript 插件协议的通用视频播放器，当前版本 0.0.1。**

HGhub 保留原有的界面风格，内容来源、解析和插件账号均由用户自行导入的单文件 JS 插件提供。
客户端不内置、不分发插件，不提供官方源列表。首次启动为空白片库，无需 HGhub 平台账号。

当前优先开发和验证 Windows。已接入插件首页、分类筛选、聚合搜索、详情、HLS/普通视频播放，
以及本地收藏、按真实分集 ID 保存的观看进度、插件登录表单与云端列表。
详情页支持作品/分集评论、回复与评论点赞，云端点赞/收藏/作者关注；“我的”支持收藏目录与关注列表。
播放开始、暂停、结束及限频心跳可回报所属插件，失败静默且不影响播放。
首页按来源显示直播与图文入口，支持纯直播源、频道分组/节目单，以及清洗后的图文正文和文内视频。
信息流支持竖屏连续播放、直接分集入口、详情回退、分页、收藏和真实分集进度，自动切换遵循播放偏好。
插件中心支持文件、网址和列表勾选导入、手动检查更新与恢复上一可用版本，站点线路可手动刷新和探测。
播放器支持候选流/清晰度选择，源与解析器的播放线路分别记忆，切换保留当前播放位置。
详情支持跨源搜索与用户确认换源，各来源收藏和进度独立保留；明确季集编号匹配后仍由用户决定是否沿用旧播放秒数。
首页支持来源/分区拖动排序与显隐；推荐、分类、搜索和分区列表支持滚动分页，失败保留内容并重试原游标。
点播、直播与信息流共用解析器选择，可按播放站点记住选择，并在设置中逐项忘记或清空。
协议仍为草案，尚未实现的能力见[实现进度](docs/plugin-protocol/IMPLEMENTATION.md)，
插件作者从[协议文档](docs/plugin-protocol/README.md)和 `src/plugins/protocol.ts` 开始。

## 本地开发

基础环境：Node.js 22、pnpm 10、Rust 1.90 或更高版本，以及目标平台所需的 Tauri 开发环境。

```bash
pnpm install --frozen-lockfile
pnpm dev             # 前端开发
pnpm app:dev         # 桌面应用开发
pnpm build           # 类型检查与前端构建
```

各平台配置位于 `src-tauri/tauri*.conf.json`。移动端及 macOS 开发需要相应平台的 SDK 和工具链。

- exFAT 等不支持符号链接的文件系统需保留 `.npmrc` 中的 `node-linker=hoisted`；部分原生构建步骤仍可能受文件系统限制。
- 依赖安装脚本的允许列表见 `package.json` 与 `pnpm-workspace.yaml`。
- 验证命令及当前支持范围见[实现进度](docs/plugin-protocol/IMPLEMENTATION.md)。
